# ChatGPT Loop Runner

指定したChatGPTチャットへ、同じ短い文字(例：「か」)を、**ChatGPTの回答が完全に終わるのを確認してから**、指定した回数だけ自動で送信するローカル専用ツールです。
「30秒待ったら次を送る」のような固定秒数の待機は行わず、必ずChatGPT画面の状態(回答開始/生成中/完了)を確認してから次を送信します。

このツールは `x-ai-editor` とは完全に独立した別プロジェクトです。

---

## 普段はこれだけ

1. `start-app.bat`(Windows)または `start-app.sh`(Mac/Linux)をダブルクリック／実行する
2. **「ChatGPT Loop Runner」という専用アプリのウィンドウ**が開く(ブラウザのタブではありません)
3. そのウィンドウで、対象のChatGPTチャットを選ぶ
4. 「送る文字」を入力する(例：か)
5. 「繰り返し回数」を入力する(例：18)
6. 「開始」を押す
7. 終わるまで待つ(進捗がアプリ画面に大きく表示されます)

初回起動時だけ、必要なファイルのダウンロードのため少し時間がかかります(数分程度、ネット環境によります)。

> ※ このアプリのウィンドウとは別に、ChatGPTを操作するための専用ブラウザウィンドウがもう1つ自動で開きます。ChatGPTへのログインはそちらの専用ブラウザウィンドウ内で行います(下記参照)。

---

## 途中で止めたい・再開したい場合

- 途中で止めたい：実行中画面の「安全に停止」を押してください。今の回答が完了・保存されてから止まります(送信済みの文字が失われることはありません)。
- 続きから再開したい：停止した状態で表示される「○回目から再開」を押してください。成功済みの回数を再送信することはありません。
- 「送信結果を確認できません」と表示された場合：二重送信を防ぐため、自動では再開しません。画面の案内(送信済みとして続ける／未送信として再実行／このrunを終了)から選んでください。

---

## 初回セットアップについて

- Node.js が必要です(インストールされていない場合は https://nodejs.org/ からLTS版を入れてください)。
- `start-app.bat` / `start-app.sh` は、初回のみ自動的に `npm install` を実行します(ネット接続が必要です)。このとき、アプリのウィンドウ表示に使うElectronと、ChatGPT自動化に使うChromiumが自動でダウンロードされます。
- ChatGPTへのログインは、アプリ起動時にもう1つ開く**専用のブラウザウィンドウ**の中で、ご本人が手動で行ってください。**パスワードやCookieはコード・設定・ログのどこにも保存されません。**

---

## 重要な注意事項

- **回答中に対象チャットを手動で操作しないでください。** 途中で別のメッセージを送ると、自動ループが想定外の割り込みとして検知し停止します。
- **対象チャットを途中で変更しないでください。** 別の会話タブへ移動すると、誤送信を防ぐためツールは自動的に停止します。
- **「送信結果を確認できません(unknown)」の状態では絶対に自動で再送信しません。** 二重送信を防ぐための仕様です。必ず画面の案内に従って人の目で確認してください。
- **ログインが切れた場合は自動ログインしません。** 表示に従い、専用ブラウザウィンドウの中で手動ログインしてから「再開」してください。
- 繰り返し回数には安全上限(既定50回)があります。詳細設定から変更できますが、無限ループの設定はできません。
- 1回の実行(1 run)は1つのChatGPTチャットのみを対象とします。複数チャットへの同時連続送信には対応していません。

## フォルダ構成

```
chatgpt-loop-runner/
  config/    設定ファイル(送る文字・回数・タイムアウト等)
  state/     実行中/過去のrunの状態(再開に使用)
  outputs/   ChatGPTの回答の保存先(run_idごとのフォルダ)
  logs/      技術的なログ(認証情報・Cookieは保存しません)
  src/       アプリ本体
  public/    ローカルGUIの画面
```

---

## トラブルシューティング

- **「ChatGPTの入力欄を確認できませんでした」と表示される**：ChatGPTのUI変更により入力欄を検出できなかった可能性があります。技術的な詳細は `logs/` に記録されています。ChatGPTの画面が完全に読み込まれているか確認し、「チャット一覧を更新」を試してください。
- **「対象チャットのタブが見つかりません」と表示される**：専用ブラウザウィンドウで対象のChatGPTチャットを開いた状態にしてから、「チャット一覧を更新」を押してください。
- **アプリのウィンドウが開かない**：ターミナル/コマンドプロンプトに表示される `http://localhost:4173` を手動でブラウザに入力すれば、同じ画面を確認できます。

---

## このツールが「やらないこと」

- ChatGPT以外のサイトへの自動入力(公式ChatGPTのURLであることを確認できない場合、入力・送信は行いません)
- 無限ループ(必ず指定回数と安全上限の範囲で停止します)
- パスワード・認証情報の保存や自動ログイン
- 複数チャットへの同時並列送信
