# はじめに(Claude Codeでの動かし方)

このフォルダには、Xバズ自動化アプリを作るために必要な資料一式が
入っています。以下の手順通りに進めれば、最短でアプリが動き始めます。

## ステップ1:X APIの準備(あなたが行う作業)

1. https://developer.x.com にアクセスし、開発者アカウントを登録する
2. 利用プランを選ぶ(自動投稿・自動取得を行うため、無料プランでは
   制限が厳しいので、Basic以上の有料プランを推奨)
3. APIキー・トークン(4種類)を発行する
   ※このキーは他人に見せない、コードに直接書き込まない
   (Claude Codeに実装時、安全な保存方法を確認してください)

## ステップ2:Claude Codeにこのフォルダを渡す

1. Claude Codeを起動する
2. このフォルダ(x-buzz-project)を開いた状態で作業を始める
3. Claude Codeに、次のように伝える:

   「このフォルダの 要件定義書.md を読んで、その内容通りに
   Xの自動運用アプリを作ってください。common_rules.txt、
   config.yaml、influencer_addon.txt、prompts/フォルダの中身は
   すべてそのまま使う設計にしてください。まずは取得→生成→
   アプリ画面での候補確認→ワンクリック投稿、という一連の
   流れが動く最小限の状態(MVP)を目指してください。」

4. X APIキーを聞かれたら、ステップ1で取得したものを伝える
   (安全な渡し方はClaude Codeの指示に従ってください)

## ステップ3:少しずつ試しながら進める

- 一度で完成品はできません。「ここを直して」「この画面の動きが
  おかしい」と、都度伝えながら進めてください
- 最初は「半自動モード」(生成された候補を、人間が確認してから
  投稿するモード)から始めることを強く推奨します
- 慣れてきたら、config.yamlの数値を調整しながら運用を最適化して
  いってください

## 困ったときは

- 「ここの設定を変えたい」→ config.yaml の該当箇所を書き換える
  (書き方が分からなければ、Claude Codeに直してもらってOK)
- 「コメントの言い回しを変えたい」→ common_rules.txt または
  prompts/comment_patterns.txt / quote_patterns.txt を編集する
- 「著名人への対応を変えたい」→ influencer_addon.txt を編集する

## このプロジェクトでまだ決まっていないこと(要件定義書 13章参照)

- 自分発信投稿(オリジナルポスト)専用のパターン
- フォロワー化・収益化の導線
- 自分のコメントへの返信が来た場合の対応方針
- マルチアカウント対応(現時点では単一アカウントのみ)

これらは実装を進めながら、追って詰めていってください。
