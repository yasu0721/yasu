# x-ai-editor

X(旧Twitter)投稿のネタ作りを半自動化するためのプロジェクトです。
初心者の方でも迷わないように、フォルダの役割と使い方をここにまとめます。

## 普段やること

1. `input/input.txt` を開いて、ニュースやX投稿を貼って保存する
2. `run.bat` をダブルクリックする(Windowsの場合。初回は自動で準備が走ります)
   もしくはターミナルで `npm run generate` を実行する
3. `final/<日時>/final.txt` を見る(編集長GPTが選んだ最終候補)

これだけです。振り分けGPTが必要な専門GPTを選び、それぞれの案を編集長GPTが
比較・統合して、最終的に1〜3案に絞ってくれます。

## 全体の流れ

1. `input/input.txt` にニュースやX投稿を貼る
2. 「振り分けGPT」が内容を読み、使う専門GPT(最大5体)を選ぶ
3. 選ばれた専門GPTへ素材と指示が送られ、案が作られる
4. 各専門GPTの回答を集める
5. 「編集長GPT」がまとめて最終候補を1〜3案に絞る
6. 結果を `final/` フォルダのファイルに保存する

## 大事な設計方針

当初はChatGPTのブラウザ画面を自動操作する方式を検討していましたが、
以下の理由から**Claude API を直接呼び出す方式**に変更しました。

- ChatGPTの画面を自動操作するには「人がブラウザを見ながら手動ログインする」
  作業が必須ですが、この作業環境(クラウド上)には画面がなく実現できません。
- 複数の「カスタムGPT」の画面を自動操作してやり取りする方式は、
  OpenAIの利用規約に触れる可能性があります。
- APIを直接呼び出す方式なら、ブラウザ操作やログインが一切不要で、
  画面のデザイン変更で壊れる心配もありません。

「振り分けGPT」「コメントGPT」などの役割は、ChatGPTのカスタムGPTではなく、
`prompts/` フォルダに保存したプロンプト(指示文)を使って、Claude APIを
直接呼び出す形で実現しています。役割ごとの人格・ルールは自由に書き換えられます。

**X(旧Twitter)への自動投稿は、まだ実装していません。** 実際に公開される
操作のため、必ず別途はっきりお伝えしてから、明確な許可を得たうえで進めます。

## フォルダの役割

| フォルダ / ファイル | 役割 |
| --- | --- |
| `input/input.txt` | 自分でニュースやX投稿を貼る場所 |
| `prompts/` | 各GPT役割のプロンプト(指示文)を保存する場所 |
| `config/gpts.json` | 各GPT役割の名前・有効/無効などの設定 |
| `outputs/` | 各専門GPTの回答を保存する場所(run_idごとにフォルダ分け) |
| `final/` | 編集長GPTの最終回答を保存する場所(run_idごとにフォルダ分け) |
| `automation/` | 自動化プログラム(スクリプト)を置く場所 |
| `logs/` | 実行結果やエラーの記録を残す場所 |

## 現在使えるコマンド

`x-ai-editor` フォルダの中で実行してください。初回だけ、必要な部品をインストールします。

```bash
npm install
```

### 素材から最終案まで一括実行する(いちばんよく使うコマンド)

```bash
npm run generate
```

`input/input.txt` の内容を読み込み、

1. 振り分けGPTが使うべき専門GPT(最大5体)を判断
2. 各専門GPTが案を作成
3. 編集長GPTが比較・統合して最終1〜3案を選ぶ

までを自動で行い、`final/<日時>/final.txt` に保存します。可能な場合は
`final/<日時>/best_1.txt` のように候補ごとのファイルも作られます。
途中の各GPTの回答は `outputs/<日時>/` にも保存されます。

振り分け結果がうまく読み取れない場合や、専門GPTの回答が1件も得られなかった
場合は、安全のためそこで停止します(壊れた内容を無理に編集長へ送りません)。

### 振り分けGPTだけ実行する

```bash
npm run router
```

`input/input.txt` の内容を「振り分けGPT」へ渡し、判断結果だけを
`outputs/<日時>/router.txt` へ保存します。

### input.txt が読み取れるか確認する

```bash
npm run read-input
```

### ブラウザが正しく動くか確認する(参考機能)

```bash
npm run test-browser
```

自動化用のブラウザ(Chromium)が正しく起動できるかを確認する動作テストです。
現在の設計ではGPTとのやり取りにブラウザは使いませんが、動作確認用に残しています。

## Claude APIキーの設定

**APIキーを設定していない場合は、ダミー(モック)応答で仕組みの動作確認だけできます。**
実際にAIの回答を得たい場合は、`x-ai-editor` フォルダ内に `.env` ファイルを作り、
以下のように書いてください(`.env` はGit管理対象外です)。

```
ANTHROPIC_API_KEY=ここに自分のAPIキー
```

もしAPIキーが「特定のワークスペースに紐づいている」タイプで、実行時に
`anthropic-workspace-id is required` のようなエラーが出る場合は、
ワークスペースIDが分かれば `.env` に以下も追加してください(任意)。

```
ANTHROPIC_WORKSPACE_ID=わかれば貼ってください
```

## プロンプト(GPTの指示文)を直すには

`prompts/` フォルダの中の、直したい役割のファイル(例: `meme.txt`)を
そのままテキストとして編集して保存するだけです。次回の実行から反映されます。
現在の各専門GPTのプロンプトはまだ初期テンプレートなので、実際に使いたい
言葉・ルールに書き換えていくことをおすすめします。

## ログについて

`logs/history.log` に、実行日時・処理名・成功や失敗などの結果が
1行ずつ追記されます。パスワードやAPIキーなどの秘密情報は記録しません。
